# Repository workflow

- After completing and verifying each requested code or documentation change, commit it to Git and push the commit to the configured upstream branch unless the user explicitly asks not to.
- Keep commits scoped to a coherent change. Do not include unrelated local changes.
- Run the relevant tests, type checks, and build before committing implementation changes.
- Do not commit credentials, Cloudflare Access email addresses, local Wrangler state, or generated build output.
